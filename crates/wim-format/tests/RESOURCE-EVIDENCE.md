# Resource reader slice

Rules read from upstream src/resource.c read_compressed_wim_resource and
include/wimlib/resource.h. API accepts full file slice and a codec callback;
whole resources only, ordinary offset tables, seekable pipable trailing tables
with size-word framing, and solid alternate header/size tables. No pipe fd
streaming, selected range reads, corruption recovery, hashing or extraction.

Tests written before module: cargo test failed E0583 missing resource module
(and other agents' in-progress modules). This is compilation-contract red,
not assertion red. Rustc isolated build passed seven behavior tests; temporary
crate roots omitted unfinished parallel modules without editing shared sources.

Three fixtures were generated by built upstream C capture; C apply and cmp
verify payload bytes for ordinary, pipable and solid XPRESS. Rust callback using
native XPRESS decodes each exact original 76810-byte payload; final chunk is
partial. Synthetic tests verify raw-chunk bypass, malformed/truncated ranges,
overflow offsets, 64-bit entries on resources above 4GiB before allocation,
solid/pipable framing, and uncompressed-reader behavior.

Preflight checks stored spans before allocating output, with checked u64/usize
conversions and fallible vector reservation. This buffers the full output, so
large resources still need an upcoming streaming API. Decoder error codes are
propagated. Pipable size words are skipped for seekable reads, as C does;
trailing table remains authoritative. Solid header overrides codec and size.

## Solid compatibility regression

A new regression first failed with Decompression on a generated solid WIM
whose final per-chunk size entry was zero. Upstream resource.c derives the
last chunk size from remaining stored resource bytes, ignoring that table
entry. Fixed both preflight and decoding loops to use that rule. Also mask
alternate codec field to 22 bits, matching assignment into the descriptor's
compression_type bitfield in blob_table.c/resource.h.

Eight cargo resource tests now pass. Built C imagex apply independently
succeeded for both mutated WIMs (zero last entry; zero last entry plus bit22
in codec field), and cmp matched the original payload for each. This confirms
acceptance and extracted-byte fidelity for the previously failing behavior.
